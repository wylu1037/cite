# 开发与接口板块说明

接口文档建议按下面的模板写，方便联调时直接对照。

## 接口模板

### `GET /api/example/items`

**鉴权**：内网网关 + 服务 Token

**请求参数**

| 参数 | 类型   | 必填 | 说明              |
| ---- | ------ | ---- | ----------------- |
| page | number | 否   | 页码，默认 1      |
| size | number | 否   | 每页条数，默认 20 |

**响应示例**

```json
{
  "items": [],
  "total": 0
}
```

**错误码**

| code | 说明     |
| ---- | -------- |
| 400  | 参数错误 |
| 401  | 未授权   |

## 联调约定

- 时间统一 ISO 8601，展示按 UTC+8
- 分页统一 `page` / `size` 两个参数
