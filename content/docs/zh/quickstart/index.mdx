# 如何使用知识库

## 浏览与搜索

- 左侧目录按板块组织；站点右上角搜索框支持**中文分词**，输入关键词即可
- 文档页右侧显示本页目录（TOC），长文方便跳转

## 后台写文档

管理员通过后台维护内容，发布后**无需重新部署**即生效：

1. 打开 `/admin`，用部门账号登录
2. 「新建文档」填写路径（如 `product/new-feature.mdx`）与标题，自动生成模板
3. 编辑器内写作，可随时「保存草稿」；确认后点「发布」上线
4. 历史版本自动进入 git，随时可查看与一键回滚

> 前台无需登录（内网环境），后台仅管理员账号可进。

## 反馈与改进

- 内容有误：直接在后台修改，或联系板块维护者
- 想加板块 / 功能：在 FAQ 板块记录，或找平台管理员
