# 产品文档板块说明

本板块存放产品功能说明、业务流程与权限设计。建议每篇按下面的骨架起稿：

## 1. 背景与目标

谁在什么场景下用这个功能，解决什么问题。

## 2. 功能说明

- 核心流程（附流程说明或截图）
- 边界与限制（明确不支持什么）

## 3. 权限与角色

| 角色     | 可见范围 | 可操作 |
| -------- | -------- | ------ |
| 管理员   | 全部     | 增删改 |
| 普通成员 | 本部门   | 查看   |
